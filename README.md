## 👩‍💻 About Me

> *"Quality is never an accident; it is always the result of intelligent effort."*

I'm a **Senior SDET** with **20+ years** in software quality assurance, specialising in **test automation for real-time trading and pricing systems**. I own test strategy for **IG Group's OTC pricing platform** (FX, options, indices, prediction markets).

I test with engineering depth: I ported production C++ pricing logic to Python as a deterministic test oracle, built **Kafka-based event-driven test automation** for distributed-system failure modes, and built **AI-augmented testing tools** (MCP server, RAG pipeline with Claude API) to speed up writing test scenarios.

In my free time I practise new automation tools, build test automation framework skeletons, and currently **build LLMs from scratch** 🧠.
